# Registro 2 — Implementação de animações e interatividade

## Tempo sugerido
25 minutos.

## Objetivo
Completar o projeto-base aplicando três habilidades da Semana 24.

## Tarefa 1 — Transition
Adicione uma transição suave em pelo menos um elemento:
- link do menu;
- card;
- imagem.

Exemplo:
```css
transition: 0.3s ease;
```

## Tarefa 2 — @keyframes
Crie uma animação simples usando propriedades como:
- `opacity`;
- `transform: translateY()`;
- `transform: scale()`.

## Tarefa 3 — JavaScript
Use:
```javascript
addEventListener()
```

e:

```javascript
classList.toggle()
```

A ideia é clicar em um card e ativar/desativar a classe `.ativo`.

## Evidências
Entregar:
1. link do repositório GitHub;
2. print do site funcionando;
3. print/trecho do CSS com `transition` ou `@keyframes`;
4. print/trecho do JavaScript.
