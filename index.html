Aula 1 • Semana 23

Esteiras de entrega contínua

Acompanhe o código desde o desenvolvimento até a entrega, entendendo onde entram automação, testes e containers.

CI

Integração Contínua

Alterações são integradas com frequência e verificadas automaticamente para reduzir falhas ao juntar código.

CD

Entrega / Deploy Contínuo

Automatiza etapas que deixam a aplicação pronta para publicação ou que realizam a implantação.

⚙

Pipeline

Sequência automatizada de tarefas. Nesta aula: build → testes → deploy.

Analogia:um pipeline CI/CD funciona como uma linha de produção: o código entra, passa por verificações e só avança quando as etapas anteriores dão certo.

Pipeline interativo

Clique em cada etapa para descobrir sua função.

→ → → → → →
Desenvolvedor

Cria ou altera o código da aplicação. O processo automatizado começa quando a alteração chega ao repositório.

TESTES

Jest × Cypress

Jest

Foco didático: testes unitários para validar a lógica do código.

expect(somar(2, 3)).toBe(5);

Cypress

Foco didático: interação e comportamento da interface pelo ponto de vista do usuário.

cy.get('#entrar').click();
DEPLOY

Docker × Kubernetes

Docker

A caixa padronizada

Empacota aplicação + dependências para executar de forma consistente em diferentes ambientes.

Kubernetes

O gerente das caixas

Orquestra containers, cria réplicas, ajuda em atualizações e pode recuperar instâncias com falha.

DEMONSTRAÇÃO

Workflow simplificado

name: CI

on:
  push:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm install
      - run: npm test

Nesta sequência condensada, SSH, Secrets, servidor e script de deploy ficam como demonstração conceitual, não como exigência do registro.

O objetivo é entender como organizar estilos e fazer um layout se adaptar a diferentes dispositivos.

PRÉ-PROCESSADORES

SASS e LESS

Pré-processadores ampliam a forma de organizar e reutilizar estilos. Nesta sequência, o foco é conceitual: não gastar a aula instalando ferramentas.

CSS
.botao {
  background: #e63946;
}

.botao:hover {
  background: #b91c2b;
}
SASS (exemplo)
$cor: #e63946;

.botao {
  background: $cor;

  &:hover {
    background: darken($cor, 10%);
  }
}

Aula 3 • Semana 24

Animações, transições e JavaScript

Perceba a diferença entre uma mudança suavizada, uma animação com etapas e uma interação disparada pelo usuário.

T

transition

Suaviza a mudança entre estados, como hover, cor, tamanho ou posição.

K

@keyframes

Define etapas de uma animação, permitindo controlar início, meio e fim.

JS

Eventos

O JavaScript reage a ações como cliques e pode adicionar/remover classes CSS.

DEMONSTRAÇÃO

Teste os três conceitos

Clique nos botões e observe o elemento ao lado.

<div>

Escolha uma demonstração.

PADRÃO DA ATIVIDADE

JavaScript adicionando uma classe

const card = document.querySelector('.card');

card.addEventListener('click', () => {
  card.classList.toggle('ativo');
});

A lógica é simples: ação do usuário → evento JavaScript → classe CSS → mudança visual.

Registro 2 • Semana 24

Prática — Animações e Interatividade

O projeto-base já está estruturado. O estudante concentra o tempo nas três habilidades que realmente precisam ser praticadas.

01

Transition

Aplicar uma transição suave em um botão, card, link ou imagem.

transition: 0.3s ease;
02

@keyframes

Criar uma animação simples com deslocamento, opacidade ou outro efeito discreto.

@keyframes entrada { ... }
03

JavaScript

Usar evento de clique e alterar uma classe do elemento.

classList.toggle('ativo')

Evidências

  • link do repositório GitHub;
  • print do site funcionando;
  • trecho/print do CSS com transition ou @keyframes;
  • trecho/print do JavaScript utilizado.
