Mapa Mental — Esteiras de Entrega Contínua

Roteiro adaptado para a sequência condensada de três aulas.

👥 Em dupla⏱ 20 minutos📌 Registro

Objetivo

Criar um mapa mental demonstrando como as tecnologias estudadas na Semana 23 se relacionam no processo de desenvolvimento, testes e entrega de uma aplicação.

Tema central

CI/CD — Esteiras de Entrega Contínua

O mapa deve conter: CI, CD, Pipeline, Build, Testes, Deploy, GitHub Actions, Jest, Cypress, Docker e Kubernetes.

Não basta listar os termos. Use setas, linhas, ramificações, palavras-chave e pequenas explicações para mostrar as relações.

Onde posso fazer?

📝 Caderno ou folha🎨 Canva📊 PowerPoint🖥 Google Apresentações🧠 Outra ferramenta de mapa mental

Sugestão: no Canva, pesquise por “Mapa Mental” nos modelos disponíveis. Escolha um modelo e adapte as ramificações para o conteúdo da Semana 23. O Canva é opcional.

Passo a passo

  1. Escolha a ferramenta.
    Papel, Canva, PowerPoint ou outra opção.
  2. Defina o tema central.
    CI/CD — Esteiras de Entrega Contínua.
  3. Crie os ramos principais.
    Sugestão: Pipeline, Testes, Automação e Deploy.
  4. Relacione as ferramentas.
    Jest → testes unitários; Cypress → interface; GitHub Actions → automação; Docker → containers; Kubernetes → orquestração.
  5. Mostre o fluxo.
    Código → Testes → Pipeline → Container → Deploy
  6. Revise.
    Confira se os 11 conceitos estão presentes e ligados de forma coerente.

Perguntas de registro

  1. Qual é a função do Jest?
  2. Qual é a função do Cypress?
  3. O que um pipeline CI/CD automatiza?
  4. Qual é a função do Docker?
  5. Qual é a diferença entre Docker e Kubernetes?

Entrega: foto ou print do mapa mental + respostas curtas das cinco perguntas.

O que será avaliado?

Presença dos conceitos obrigatórios, organização visual, relação entre os conceitos, clareza, compreensão de CI/CD, diferença entre Jest e Cypress, diferença entre Docker e Kubernetes e conclusão das perguntas.
